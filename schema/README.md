# 输出结构 · 使用与扩展说明

`schema/assessment.json` 定义的是一份**判定结果**的字段，不是判定方法本身。

## 为什么只有形象场景

因为「人」是第一份完整样板。版式、空间、声音等场景的判定，结构相同，但字段含义不同：

- 形象场景的 `parameters` 是「廓形 / 色彩 / 材质 / 细节」
- 版式场景会变成「grid / 层级 / 留白 / 字重」
- 空间场景会变成「动线 / 材质 / 光 / 比例」

**强行共用一个字段表，会让所有场景都判得含糊。** 所以当前只定义形象场景。

## 怎么扩展到别的场景

不改动本文件，另开一个：

```
schema/assessment.image.json     ← 当前这份（形象）
schema/assessment.layout.json    ← 版式（待做）
schema/assessment.space.json     ← 空间（待做）
```

三份之间共享的字段只有四个：

| 共享字段 | 含义 |
|---|---|
| `subject` | 谁、什么场合、要干什么 |
| `prototype` | 主原型 / 主调性 |
| `blockers` | 卡点 |
| `selfCheck` | 三条硬判据的结果 |

其余字段各自定义。

## 一个约定

`actions` 最多三条，且每条必须能在下一次直接执行。

**这条约定比字段本身更重要。** 判定如果落不到动作，它就只是评论。
