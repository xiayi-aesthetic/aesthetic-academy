# 从公理到取值：一份可复核的推导示范

> 星帷指出的缺口：公开层只给了结论，没有给「怎么从公理走到具体取值」。
> 这份文档补的就是这一段——**任何一条参数，都必须能回溯到一条公理。**

---

## 推导的四步（不可跳步）

```
公理  →  功能要求  →  视觉要求  →  具体取值
（相信什么） （要解决什么） （视觉上意味着什么） （买什么、穿什么、怎么搭）
```

**跳步的典型症状**：直接从「高级感」跳到「买黑色西装」。中间三步全没有，这叫模板，不叫推导。

---

## 完整示范：一条参数是怎么长出来的

### 起点 · 公理

> 形象 = 内在认知的外在显化。

### 第一步 · 功能要求

若内在秩序是「少而精、经得起时间」，那么形象要满足三个功能要求：

1. 不追当季（追了就会被时间淘汰）
2. 每件单品能互相组合（组合成本低，才可持续）
3. 经得起近距离看（近距离露怯，会反噬信任）

### 第二步 · 视觉要求

把功能要求翻译成视觉语言：

| 功能要求 | 视觉要求 |
|---|---|
| 不追当季 | 廓形线条连续、无当季装饰符号 |
| 能互相组合 | 色系统一在窄区间内、材质调性一致 |
| 经得起近距离 | 面料有筋骨、无廉价反光、工艺无可挑剔 |

### 第三步 · 具体取值

| 视觉要求 | 取值 |
|---|---|
| 线条连续 | H 型直身，不做过多的分割与拼接 |
| 色系窄 | 黑、灰、藏蓝、驼（四个色之间任意两两可搭） |
| 有筋骨 | 精纺羊毛、挺括棉、高支针织 |
| 无廉价反光 | 避开涂层、亮面、化纤混纺 |

### 第四步 · 反向检验（这一步不能省）

拿任何一条取值往回问：**它服务哪条功能要求？**

- 「H 型直身」→ 服务「线条连续」→ 服务「不追当季」→ 公理成立。
- 如果某条取值往回问不出功能要求，它就是**个人偏好**，不是推导结果。

**这条检验，就是本体系和「穿搭博主」的分界线。**

---

## 反例：一条没有推导的取值

> 「高级感要穿黑色。」

往回问：
- 它服务哪条功能要求？答不出。
- 它服务哪个场域？所有场域？那它就是万能话术。
- 换到葬礼、婚礼、海边，它还成立吗？

**答不出，就是偏好冒充标准。** 偏好可以有，但必须标注为偏好，不能写进公理。

---

## 这套推导的实际用途

1. **判别人**：拿到一套方案，先问它能不能回溯到公理。回不去，就是拼凑。
2. **教别人**：把推导链给对方看，他能自己举一反三，而不是记住结论。
3. **改自己**：换季、换场域、换身份时，只要公理不变，取值可以重新推导，不用推翻重来。

---

## 附录：推导链的书写格式

```
【公理】形象 = 内在认知的外在显化
  └─【功能】经得起时间 / 可组合 / 经得起近看
      └─【视觉】线条连续 / 色系窄 / 有筋骨
          └─【取值】H 型直身 · 黑灰藏蓝驼 · 精纺羊毛
```

任何一份交付，都应该能画出这张链。画不出来，就是没想清楚。
